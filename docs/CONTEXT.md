# Project Context

## Objective
Build a modular, self-hosted, evidence-grounded Web AI Agent.

## Hardware
Primary environment consists of:
- This computer: control/application node
- Ollama host: AI compute node

## Technology Baseline
- Google ADK
- Python
- PostgreSQL + pgvector
- Ollama
- multilingual-e5-large-instruct
- bge-reranker-v2-m3
- configured LLM via Ollama
- SQLite
- HTML/CSS/JavaScript
- Docker

## Interaction
Web browser only.

## Core Principle
Keep orchestration, retrieval, storage, inference, and presentation decoupled.
